## 📖 游戏背景

你欠了房东 **50,000** 元，限期 **15** 天还清。带着仅有的 **5,000** 元本金，你在夜市支起了一个小摊。烤冷面、潮袜、蓝牙耳机、限量球鞋、显卡……行情每天都在变。低买高卖、囤积居奇，15 天后，你能逆天改命吗？

## 🎯 游戏目标

在 15 天内，通过倒买倒卖让总资产达到 **50,000** 元以上还清债务。赚得越多，结局越好：

| 总资产 | 结局 |
| --- | --- |
| ≥ 150,000 | 🏆 商业传奇 |
| ≥ 80,000 | ☀️ 小有积蓄 |
| ≥ 50,000 | 🌧️ 勉强还债 |
| < 50,000 | 💀 破产流浪 |

## 🕹️ 玩法说明

- **📈 今日行情**：8 种商品分三档价位，波动幅度各不相同。点击「买1 / 买10」进货，注意现金和背包容量
- **🎒 我的背包**：显示每件商品的持仓均价和浮动盈亏，点击「卖1 / 全卖」出货（红涨绿跌）
- **📊 价格走势**：每个商品带迷你走势线，下方大图可切换商品、悬浮查看任意一天的涨跌幅——像看股票一样复盘行情
- **🔥 市场热度**：每个商品都有 0~100 的热度徽章，热度真实影响次日涨跌概率，爆表（95+）后小心见顶回落
- **📻 夜市新闻联播**：每天收摊后免费播报一条明日预告（价格风向 / 事件风向），措辞含蓄但 75% 会应验——学会读懂暗示
- **📰 情报站**：花钱买明天的确定性——街头传闻（¥300，五成把握）/ 批发内幕（¥1,000，七成把握）/ 核心线报（¥3,000，九成把握），每天限购一次，次日揭晓真伪
- **🌙 收摊**：结束当天，进入下一天，商品价格重新波动
- **🏦 银行**：存款不会被偷、不会被罚款（但没有利息）
- **💸 借贷**：向"老王"借钱加杠杆，日息 5%，收摊自动复利——高手神器，新手深渊
- **🎒 扩容**：花钱扩大背包容量（20 → 40 → 70 → 100 格）
- **🎲 随机事件**：城管罚款、小偷偷窃、网红带货、批发商深夜推销、神秘人内幕消息……每天 55% 概率触发，同一事件两天内不重复，部分事件需要你做抉择
- **🏅 成就系统**：9 个隐藏成就等你解锁（满仓显卡、杠杆玩家、冤大头……）
- **💾 自动存档**：进度保存在浏览器本地，随时关掉、随时继续

## 🛠️ 技术栈

纯前端、零框架、零依赖，开箱即用：

- **HTML5 + CSS3**（CSS 变量、Grid/Flex、毛玻璃 `backdrop-filter`、渐变动画）
- **原生 JavaScript（ES6 Modules）**：游戏逻辑、行情算法、事件系统
- **Web Audio API**：实时合成音效，无外部音频文件
- **localStorage**：自动存档 + 历史最佳记录

## 🚀 本地运行

这是纯静态页面，直接用浏览器打开 `index.html` 即可；也可以启动本地服务器（推荐，ES Module 需要 HTTP 环境）：

```bash
npm run dev        # 默认 http://localhost:7100
npm run dev -- --port 8080   # 指定端口
```

## 🌐 部署（GitHub Pages）

1. 将本仓库推送到 GitHub
2. 仓库页面 → **Settings** → **Pages**
3. **Source** 选择 `Deploy from a branch`，分支选 `main`、目录选 `/(root)`，保存
4. 约 1 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

无需任何构建步骤，`index.html` 位于仓库根目录即可直接部署。
